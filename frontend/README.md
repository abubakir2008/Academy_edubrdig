# EduBridge Frontend

Next.js 15 (App Router) + TypeScript + Tailwind 4. Живёт рядом с `platform/`,
а не внутри неё: это отдельный деплой, связанный с бэкендом только через
Traefik-гейтвей (`/api/<service>/...`).

```
academy.edubridge-backend/
├── frontend/    ← этот проект
├── platform/    ← бэкенд-микросервисы, docker-compose, Traefik
└── TZ-backend/
```

## Запуск

```bash
cp .env.local.example .env.local   # при необходимости поправьте API_GATEWAY_URL
npm install
npm run dev                        # http://localhost:3000
```

Бэкенд поднимается отдельно из `platform/` (`docker compose up`). Если гейтвей
недоступен, публичные страницы всё равно рендерятся — просто без данных каталога.

В `platform/docker-compose.yml` фронтенд собирается как сервис `frontend` с
контекстом `../frontend`, а Traefik отдаёт ему всё, что не начинается с `/api`
(router `frontend`, priority 1).

## Страницы

| Маршрут        | Что делает                                                                 |
| -------------- | -------------------------------------------------------------------------- |
| `/`            | Лендинг: конструктор запроса, направления, «как это работает», топ-репетиторы |
| `/onboarding`  | Визард из 9 вопросов (что / зачем / как) → фильтры каталога + бриф в профиль |
| `/tutors`      | Каталог с фильтрами; состояние живёт в URL, поэтому ссылка шарится           |
| `/tutors/[id]` | Анкета репетитора: расписание, сертификаты, отзывы, бронирование, избранное  |
| `/login`, `/register` | JWT-авторизация (`/auth/*`), роль student/tutor при регистрации      |
| `/dashboard`   | Кабинет ученика: уроки, избранное, заявка, прогресс                          |

## Как визард ложится на бэкенд

`src/lib/catalog.ts` — единственный источник правды по направлениям и вопросам.

- Ответы «предмет» → `?language=` (языковые направления) или `?category=`
  (остальные, матчится по `specializations`).
- Бюджет → `max_price_cents` (минорные единицы, как в API).
- Пожелания → `native_speaker`, `verified_only`, `has_trial`,
  `min_experience=5`, `min_rating=4.5`.
- Цель, уровень, ритм и расписание фильтров не имеют — они складываются в
  текстовый бриф и уходят в `PUT /students/me` (`learning_goals`, `level`,
  `learning_languages`), чтобы репетитор видел контекст заявки.

Добавить направление или вопрос = отредактировать `CATEGORIES` в `catalog.ts`;
шаги, прогресс-бар и маппинг в фильтры подстроятся сами.

## Дизайн

Тёплая бумага (`--color-paper`) вместо белого, чернильный `ink`, брендовый
фиолетовый `aurora` и цитрусовый акцент, серифный дисплейный шрифт (Fraunces)
поверх Inter, повторяющийся мотив «моста» — арки в логотипе, разделителях и
карточках. Токены — в `src/app/globals.css` (`@theme`).
